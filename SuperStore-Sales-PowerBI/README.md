&#x20;**SuperStore Sales Dashboard \& 15-Day Forecast**



&#x20;**About the Project**



This project is an interactive SuperStore Sales Dashboard created using Microsoft Power BI.



The main goal of this project is to understand sales performance through different business aspects such as sales, profit, quantity, regions, categories, customers, and shipping methods. I also created a 15-day sales forecast to understand possible future sales trends.



The dashboard is designed to make the data easy to understand through interactive charts, KPIs, filters, and visualizations.



\## Project Objectives



The project focuses on understanding overall sales and profit performance, identifying regions and cities with higher sales, comparing different product categories and sub-categories, analyzing monthly sales and profit trends, understanding customer segments and payment methods, comparing shipping modes, viewing sales across different locations, and analyzing possible future sales trends using forecasting.



\## Dashboard Features



\### Sales Dashboard



The sales dashboard includes total sales, total profit, total quantity, average delivery time, sales by region, sales by payment mode, sales by customer segment, monthly sales year-over-year, monthly profit year-over-year, sales by shipping mode, sales by category, sales by sub-category, and city-wise sales analysis using a map.



\### Forecast Dashboard



The forecast dashboard includes historical daily sales, sales trend analysis, a 15-day sales forecast, forecast range, and city-wise sales information.



\## Tools Used



Microsoft Power BI was used for dashboard development and visualization.



Power Query was used for data cleaning and transformation.



Data analysis techniques were used to identify useful patterns and insights.



Data visualization was used to present the information through interactive charts.



Forecasting was used to understand possible future sales trends.
